# CCAO-F Skills Map

*For each of the 21 skills in Anthropic's CCAO-F exam guide (version 1.1), as the book's [Appendix C](https://agentfactory.panaversity.org/appendices/exams/associate-foundations/overview/#the-map-the-guides-21-skills) lists them: where this bootcamp practises it, the file that proves you did, and how it is assessed. Checked against Appendix C on 26 November 2026.*

This bootcamp prepares you for the exam; it doesn't replace it. "Main" is the step where the skill is taught and graded most directly; "Also" is where you practise it again. "Instr." is the numbered instruction in the step's **Do it with Claude**. Every step is graded with the rubric in [SUBMITTING.md](../SUBMITTING.md#9-how-each-step-is-graded); the capstone (step 24) and the five project defences assess the skills again, on your own work and in your own words.
